# Paige — PWS V0.2

An iPhone-first personal AI web app.

## V0.2

- Dark purple mobile-first interface
- OpenAI-compatible endpoint configuration
- Model, API key and temperature controls
- Editable Paige system prompt
- Connection test
- Local chat history
- Regenerate and Continue controls
- Loading and error states
- Installable PWA shell

## Run

This version is static and can be served by GitHub Pages or any static web server. Open AI Settings in the app and enter an endpoint, model and API key.

> Note: browser-side API keys are stored in localStorage on the device. This is suitable for private prototyping, not a production credential architecture.
